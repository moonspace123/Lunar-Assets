## 数据与命名说明

- `anorthosite` 通常对应斜长岩，`basalt` 对应玄武岩；当前两个原目录的中文标签疑似对调。为保持原始材料，未擅自更名或重判岩性。
- `真实月面数据/` 为压缩包原目录名，文件名中的地点、来源、分辨率标签尚未依据原始产品元数据独立核验。PNG/JPG 预览不能替代原始高程产品。
- `全球_LOLA真实高程数据_4ppd_uint16.tif` 为 1440×720 的 uint16 TIFF，当前包内没有配套高度缩放/偏移、基准和原始下载记录；直接作为物理高程使用前需要补齐这些信息。
- 纹理中的高度/位移图表示材质细节，不等同于真实月球 DEM。把它们用于显示或几何位移时应分别记录用途。
